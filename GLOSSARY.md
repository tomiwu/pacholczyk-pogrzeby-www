# Glossary

- **NAP**: Name, Address, Phone. Must be identical on the site, in JSON-LD and (later) on Google Business Profile. This business has two offices (Uniejów and Turek) and two telephone numbers.
- **LCP**: Largest Contentful Paint. Time until the largest visible element is drawn. Target: below 2500 ms (lab, mobile).
- **JSON-LD**: structured data (schema.org) in a `<script type="application/ld+json">` block.
- **FuneralHome**: a schema.org type for a funeral home (a kind of `LocalBusiness`). This site publishes one `FuneralHome` object per office.
- **Static export**: Next.js `output: 'export'`. The build writes plain HTML, CSS and JS files to `out/`.
- **Sandcastle loop**: the program on the box that takes issues with the label `Sandcastle`, lets Claude Code write the code in a Podman container, and opens pull requests.
- **needs-validation**: label for a PR or issue that waits for Tomasz.
- **backlog**: label for work that is out of the current loop (for example the later Supabase form backend).
- **Stone Olive**: the light theme (warm stone and olive).
- **Candle Graphite**: the dark theme (deep graphite and candle light).
- **Kolegiata**: the collegiate church in Uniejów. Scene 1 shows its nave and the fresco of the translation of the relics of St Bogumił (procession from the castle, over the Warta river, to the church).
- **prefers-reduced-motion**: the visitor setting that turns the scroll story into four still images.
- **Preview**: the GitHub Pages copy of the site. It must stay `noindex` until Tomasz launches the site.
